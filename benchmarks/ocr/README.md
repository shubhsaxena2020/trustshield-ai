# OCR validation corpus

This directory contains a deterministic, synthetic corpus generated by
`scripts/make_ocr_corpus.py`. Every fixture has an image and a same-stem `.txt`
ground-truth transcription; `manifest.json` records the requested degradation,
critical security tokens, and the font file used.

Ground truth includes every visible drawn string in reading order, including
the `Synthetic TrustShield chat` header. It is generated from the same string
list used to render each image; `tests/unit/test_ocr_corpus_integrity.py`
guards against drift.

The messages, organizations, domains, and phone numbers are synthetic test
data. The rendered fonts and layouts are deliberately clean and controlled;
real-world screenshots will differ substantially in typography, compression,
backgrounds, language, and capture quality. Benchmark results therefore do not
generalize to real-world OCR accuracy.

Regenerate the corpus with:

```powershell
.venv\Scripts\python scripts\make_ocr_corpus.py
```

Run the real-Tesseract benchmark from the repository root with
`TESSERACT_CMD` explicitly set. The benchmark never falls back to mock OCR.
