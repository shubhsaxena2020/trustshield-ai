# UI sources and licences

- Android Material 3 and Jetpack Compose accessibility guidance: [Minimum 48 dp touch targets](https://developer.android.com/develop/ui/compose/accessibility/api-defaults). Used as implementation guidance for touch targets, semantics, and simple controls. No sample assets or source code copied.
- Android's official [Jetpack Compose samples](https://github.com/android/compose-samples) were reviewed as a permissively licensed source of interaction patterns. Repository states Apache License 2.0. No sample source, artwork, or other assets were copied into TrustShield.
- Existing TrustShield decisions remain authoritative for monochrome Black/White themes, the 5-tab navigation, English/Hindi/Hinglish copy, and risk color semantics: `UI_DECISION.md`, `UI_SPEC.md`, and `UI_PATTERNS.md`.

The Bomb Shield screen follows the existing app navigation/copy patterns, keeps the five primary tabs fixed, gives the demo and status live-region semantics, and uses a scrollable layout for larger font scales. It uses no proprietary app assets.
