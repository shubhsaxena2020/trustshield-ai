# TrustShield AI landing app

Standalone Next.js app for the public TrustShield AI overview. It follows the React and Next.js stack already used by `apps/web`; this app uses Next.js 16.4.3, which includes the available security fixes.

```powershell
cd apps/landing
npm install
npm run dev
```

The first-screen “Try it now” link points to the existing web checker. The Android download is marked unavailable until an official release link exists. Privacy copy distinguishes Android's local scan path and disabled-by-default API enrichment from the web API and signed-in history path. Speech-recognition behavior can depend on the device.
